# 영상 및 라벨

팀 공유 위치는 **미정**입니다. 실제 데이터는 이 저장소에 포함하지 않습니다.

- `raw/`: 원본 영상과 메타데이터
- `derived/`: 클립·크롭·추출 프레임
- `labels/`: 버전별 실제 라벨
- `releases/`: 파일 해시와 분할을 포함한 배포 manifest
- `examples/`: Git에 포함하는 합성 예시·기록 양식

[데이터 관리 규칙](../docs/data-management.md)에 파일명, 좌표, 프레임 기준, 분할과 버전을 정의했습니다. 공유 위치 확정 후 해당 버전의 파일을 받아 위 경로에 배치하고 SHA-256을 확인합니다. 현재 다운로드 링크는 없습니다.

초기 로컬 자료의 범위와 한계는 [테스트 자료 v1](../docs/testset-v001.md)을 참고하세요. 실제 파일은 Git에 포함되지 않습니다.

현재 선택 프레임 분석용 자료는 `testset-v003`입니다. [포인터 보정·수동 라벨 안내](../docs/manual-labeling.md)에 따라 manifest의 `image_path`(보정본)와 `ignore_mask_path`를 함께 사용합니다. 원본과 라벨을 그린 검토 이미지는 분석 입력으로 사용하지 않습니다.
