스트존 · 영상 업로드 판정

폰 한 대의 공 궤적과 타자 자세를 이용한 참고 판정. 실제 ABS 판정은 아닙니다.

1. 영상 업로드

고정 카메라 영상, 최대 1GB. 업로드한 파일은 이 PC에만 저장됩니다.

2. 홈플레이트와 투구 시작 지정

타자가 준비한 프레임에서 홈플레이트의 좌우 끝 두 점을 클릭하세요. 존 높이는 타자 관절로 자동 계산합니다.

준비 자세 자동 선택

약 0.2초간 안정된 자세에서 높이를 확보하고, 연속된 큰 움직임이나 투구 시작에 고정합니다. 안정 자세를 못 찾으면 준비 자세 기준 프레임을 직접 선택하세요. 타자를 잘못 선택하면 타자 선택 보조 영역을 그려 다시 분석하세요. 안정 구간이 부족하면 같은 타자의 유효 관절 중앙값을 사용하고, 관절도 부족하면 그려 둔 대체 존을 사용합니다. 둘 다 없으면 판단 불가입니다.

수동 높이 두 점을 그려두면 자동 높이를 못 잡았을 때 대체 존으로 사용합니다. 타자 없음 체크 시에는 수동 높이를 우선합니다. 한 번에 투구 한 개를 분석합니다. 같은 영상에서 시작 프레임을 바꿔 다른 투구도 분석할 수 있습니다.
