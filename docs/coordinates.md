# 좌표 및 시간 기준
상태: 미확정. 각 모듈을 연결하기 전에 아래 항목을 합의합니다. 아직 값이나 계산식을 확정하지 않습니다.

## 이미지 좌표
- 원본·리사이즈·크롭·앱 미리보기 좌표의 구분과 변환
- 원점, 축 방향, 픽셀/정규화 단위
- 가로·세로, 회전·좌우 반전 처리
- 박스·공 중심·관절·홈플레이트 꼭짓점 표현과 순서
- 검출 신뢰도와 누락 좌표 표현

## 공간 및 판정 기준
- 영상 좌표와 실제 공간 좌표의 구분
- 홈플레이트 기준 위치, 실측 단위와 보정 방법
- 존 상·하단, 좌우 경계 계산과 존 고정 시점
- 단일 카메라의 통과 시점 추정 및 판정 불가 조건
- 공 반지름·경계 접촉 처리와 판정에 쓰는 위치

## 프레임 및 시간
- 영상·투구·프레임 식별자
- 촬영 타임스탬프 단위와 기준, 서버 수신 시각과의 구분
- 파일 FPS와 실제 촬영 FPS, 슬로모션 재생 속도 구분
- 누락·중복·가변 간격 프레임 처리
