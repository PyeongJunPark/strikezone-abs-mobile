# 도착점 오검출 연결 보정

## 문제와 변경

V07-R05는 포구 사건을 감지한 결과가 아니라 `closest_observation_to_receiver` 대체 규칙으로 f2969를 선택했다. 정상 비행은 프레임마다 약 14px 내려갔지만 f2969에서 약 49px 뛰고 f2970에서는 거의 멈췄다. 기존 단일 이상점 필터는 원래 경로로 돌아오는 한 점을 대상으로 하므로 이 구간을 제외하지 못했다.

`filter_track`에 다음 보수적 조건을 추가했다.

- 실제 관측 4개의 속도가 안정적인지 확인하고 프레임 차이로 속도를 계산한다.
- 다음 점의 이동이 예상 이동량의 2배를 넘고, 예측 잔차가 `max(8px, 공 상자 짧은 변 중앙값 × 2, 예상 이동량 × 1.5)`를 넘는지 확인한다.
- 그 다음 관측의 속도가 기존 속도의 25% 이하이면 점프 후 정지 구간으로 보류한다. 지속적으로 움직이는 반사·바운드는 이 조건만으로 제외하지 않는다.
- 짧은 시간 안에 원래 경로로 복귀한 두 이동 관측이 있으면 다시 연결한다. 그렇지 않으면 이후 구간은 연결 미확인으로 판정에서 제외한다. 제외된 모든 점이 오검출이라는 뜻은 아니다.
- 제외로 생긴 추적 종료를 공 소실·포구의 근거로 사용하지 않는다. 이전의 유효한 사건이 없으면 가까운 점 대체 대신 남은 공 크기·궤적 관측으로 예측한다. 예측 근거가 부족하면 판단 불가로 남긴다.
- 결과 영상은 제외 후보를 회색으로 표시하고, 관측과 예측 위치의 출처를 구분한다. 경계 스트라이크 정책은 유지한다.

## 검증과 산출물

- 회귀 테스트: 점프 후 정지, 정상 정지 포구, 움직이는 반사, 프레임 간격, 짧은 재연결, 가짜 소실 사건 방지, 제외점을 예측 학습에서 배제하는 7개 테스트 추가.
- 기존 테스트와 함께 실행. 영상 프레임 수 검증은 파일 생성 무결성 확인이며 판정 정확도 측정이 아니다.
- 로컬 `도착오검출개선/`에 `comparison.json`, 투구별 `before.json`, `result.json`, 대표 9개 `analysis.mp4`, 변경 2개 `frames.jpg`를 저장했다. 원본 영상과 분석 데이터는 Git에 포함하지 않는다.
- 이번 규칙은 급격한 점프 후 정지하는 유형을 대상으로 한다. 부드럽게 움직이는 오검출, 단일 말단 오검출, 긴 가림 뒤 재연결, 예측 시점 오차를 모두 해결하지는 않는다. 임계값은 영상 실험용 휴리스틱이다.

## 후속 확인: 프레임 정렬 오류와 두께 재측정

위 표는 기존 저장 크기 값을 고정한 이상점 필터 비교다. 이후 V06-R07의 모든 크기 값이 null인 원인을 재현했다. `VideoCapture.set(1, start)`로 이동한 이미지와 순차 디코딩 이미지를 SHA-256으로 비교했으며, f3489라고 붙였던 이미지는 실제 순차 f3488, f3496은 f3495, f3498은 f3497과 일치했다. 한 프레임 앞선 이미지에 현재 공 좌표를 적용하여 마스크가 배경/사람에 걸렸고, 대비 부족 또는 탐색 경계 조건으로 측정이 거절됐다.

분석 파이프라인과 웹 프레임 미리보기 모두 처음부터 순차 디코딩하여 프레임 번호를 맞추도록 수정했다. 앞 구간은 grab만 하고 필요한 구간만 이미지로 가져온다. 긴 원본의 뒤쪽을 요청하면 이전보다 느리므로 짧은 투구 클립 사용을 권장한다. 크기 관측마다 측정/거절 이유를 기록하고 결과에 `frame_read_mode=sequential_decode`를 남긴다.

V06-R07은 정상 궤적 f3489~3496에서 8개 두께(약 14.36~11.37px)를 확보했다. f3497~3498은 사람 영역과 섞이며 마스크가 탐색 경계에 닿아 제외됐다. f3501~3502의 후보도 마스크 크기는 측정되지만 이상점 필터에서 제외하므로 예측에 사용하지 않는다.

새 크기로 계산한 V06-R07 결과는 f3537.66, (204.33, 2094.74)의 화면 밖 예측이며 기존 화면 밖 볼 정책에 따라 `BALL_ESTIMATE`다. 마지막 정상 위치 관측보다 약 40프레임, 약 1.3초 뒤까지 외삽한 결과로, 두께 값 복구가 실제 통과 시점 검증을 의미하지 않는다. 장거리 외삽의 불안정성은 남아 있다.

전체 93투구에서 원본을 순차 디코딩하고 두께를 다시 측정했다. 검출 좌표·존·자세는 고정했으며 모델 재추론은 하지 않았다.

## 전체 영상 동기화와 관측/예측 구분

`전체프레임동기화/`에 93투구 전부를 생성하고 16,409프레임 디코딩을 확인했다. 선택 위치 출처는 관측 72, 예측 13, 보간 2, 판단 불가 6이다. 현재 관측은 해당 프레임의 초록 빈 원과 OBSERVED 라벨로, 과거 관측은 진초록 작은 점으로 구분한다. 선택된 관측 위치는 하늘색, 예측은 자홍색, 보간은 주황색이다. 예측 원은 소수 프레임 올림 시점 한 프레임에만 표시한다. 기존 ±1프레임 표시를 제거하여 실제 선택 시점 전에 원이 보이지 않게 했다.

과거 새 모델 검출 5사례의 첫·중간·마지막 검출 당시 이미지도 순차 원본과 SHA-256으로 대조했다. V06-R01/V07-R05/V08-R01/NEW09-P01은 일치했고, V09-R14는 7프레임 차이가 있었다. V09-R14는 모든 공 관측 및 관절 표본의 이미지 일치로 프레임을 재매핑하고 두께와 판정을 재계산했다. 관측 판정 프레임 f6996이 실제 f6989로 수정됐고 좌표와 볼 추정은 유지됐다. 다른 저장 관측의 실제 공 여부를 전부 정답 라벨링한 검증은 아니다.

표시 시점 테스트를 추가해 기존 저장소 테스트 포함 125개가 통과했다. V07-R05의 예측 원은 f2973에서만, V09-R14의 선택 관측 원은 f6989에서만 나타나는 전후 3프레임을 별도 이미지로 확인했다. 웹 결과 설명은 전체 클립 분석 후의 참고 결과이며 실시간 예측 성능 검증이 아니다.

## 이상점 제거 후 포수 근처 소실 재검증

이상점으로 궤적 끝을 제외하더라도 정상 관측의 포수 근처 소실을 별도로 검사한다. 마지막 4개 관측이 부드럽게 접근하고 마지막 점이 도달 영역 안에 있으며, 이후 약 0.2초의 원시 검출 프레임이 모두 존재해야 한다. 제외된 후보까지 포함한 원시 검출 중 예상 진행 경로를 잇는 후보가 있으면 소실로 인정하지 않는다. 영상 종료나 검출 프레임 누락도 소실 증거로 사용하지 않는다. 기존 바운드·이탈 사건은 우선한다.

V07-R05는 이 조건을 충족하여 예측 f2972.59 대신 마지막 정상 관측 f2968을 사용한다. 원본 f2967~2974를 확인하면 공이 올라온 글러브 쪽으로 접근한 뒤 보이지 않는 모습이다. 자동 판정은 글러브 접촉을 검증하지 않으므로 포구 또는 가림 추정이며 `confirmed_contact=False`, `catch_or_occlusion_not_distinguished`를 유지한다. f2968 공 중심은 지정 존 상단보다 약 10.77px 높아 볼 추정은 유지된다.

같은 저장 검출·존을 사용한 93투구 재계산에서 위치 선택 방식 변경 1개(V07-R05), 스트라이크/볼 결과 변경 0개였다. 다른 92개 결과는 유지된다. 새 모델 재추론이나 정답 정확도 검증은 아니다. `포구소실재검증/`에 전체 비교 JSON, 변경 사례 영상(180프레임 디코딩 확인), 전후 비교 페이지와 원본 연속 프레임을 저장했다. 기존 테스트와 회귀 테스트 총 131개 통과. 새 6개 테스트는 소실 수용, 먼 위치 거절, 원시 프레임 부족, 제외 후보의 전진 연속성, 정지 관측, 영상 종료를 검증한다.
