# 단일 카메라 촬영 가이드 v1

상태: 초기 촬영 체크리스트. 직접 촬영한 원본으로 권장 수치를 검증하기 전이며 고정 거리·높이를 확정하지 않습니다.

## 촬영 전
- [ ] 폰을 투수 뒤쪽에서 좌우로 비껴난 안전한 위치에 삼각대로 고정한다.
- [ ] 투수에 가리지 않는 타자 전신, 홈플레이트, 공의 접근 구간이 한 화면에 들어오는지 확인한다.
- [ ] 실제 규격 홈플레이트의 앞변을 확인할 수 있도록 정리한다.
- [ ] 타자 없이 홈플레이트 기준 프레임을 별도로 촬영한다. 이후 카메라 위치·줌은 유지한다.
- [ ] 촬영 인물과 팀 공유·공개 범위를 확인하고 기록한다. 개인정보·권한 증빙은 공개 Git에 올리지 않는다.
- [ ] 기종, 카메라 렌즈, 촬영 방향, 해상도, 선택 FPS, 조명, 대략적인 설치 조건을 기록한다.

## 짧은 시험 촬영
- [ ] 먼저 밝고 일정한 조명에서 1~2구를 찍어 타석 부근의 공이 구분되는지 확인한다.
- [ ] 기기가 지원하는 일반/고속 모드를 각각 시험하고 실제 원본 정보와 재생 방식을 확인한다.
- [ ] 타자 관절과 공이 보이지 않으면 줌·거리·조명을 조정하고 새 조건으로 기록한다.
- [ ] 디지털 확대는 원본에 없는 정보를 복원하지 않으므로 확대 화면만 보고 해상도가 충분하다고 판단하지 않는다.
- [ ] 모션 블러, 포수·타자·투수 가림, 자동 초점·노출 변화가 있는지 프레임별로 확인한다.

## 본 촬영과 전달
- [ ] 준비 자세부터 투구·포구 후까지 여유 구간을 포함한다.
- [ ] 촬영 중 이동·줌·렌즈 전환을 하지 않는다. 바뀌면 새 세션으로 분리한다.
- [ ] 우선 10~20개의 서로 다른 투구를 목표로 하되 실패 사례도 보존한다.
- [ ] 화면 녹화나 메신저 재압축본 대신 카메라 원본을 파일로 전달한다.
- [ ] 홈플레이트 통과 판정 정답은 별도 검증 장치/절차 없이 표시하지 않는다.
- [ ] 원본 해시, 파일 FPS와 확인된 촬영 FPS·재생 배속을 각각 기록한다. 모르면 null이다.

## 현재 테스트 자료를 다듬는 원칙

원본을 보존하고 구간 자르기·영상 외곽 UI 크롭만 별도 파생본에 적용한다. 크롭 원점, 원본 프레임 번호, 해시를 남긴다. 공이나 관절과 겹치는 재생 버튼·포인터는 인페인팅/보간으로 제거하지 않고 불확실·가림으로 표시한다. 파생 미리보기는 손실 압축될 수 있으므로 좌표 라벨은 원본 프레임에서 작성한다.
