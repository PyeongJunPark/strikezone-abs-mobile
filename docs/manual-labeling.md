# 포인터 보정과 수동 라벨 초안

이슈 #10의 로컬 자료 `testset-v003`입니다. 6개 영상에서 투구 구간 **38개 프레임**을 선택해 원본을 확대 관찰하고 직접 좌표를 기록했습니다. 전체 프레임을 주석 처리한 자료가 아니며, 모델 추론이나 좌표 보간으로 라벨을 생성하지 않았습니다.

이슈 #10은 초기 자료 구축 범위로 마무리합니다. 촬영 원본 확보·등록, 라벨 독립 검토·보강, 공유 위치·사용 조건 확정은 후속 이슈에서 처리합니다. 이슈 종료가 해당 항목의 완료나 라벨 정확도 검증을 뜻하지는 않습니다.

## 현재 자료

| 영상 | 원본 프레임 번호 | 공 중심 | 관절 좌표 | 포인터 보정 프레임 |
| --- | --- | ---: | ---: | ---: |
| 1 | 60, 65, 70, 75, 80, 85 | 5 | 18 | 6 |
| 2 | 24, 26, 28, 30, 32, 34, 36, 38 | 8 | 24 | 5 |
| 3 | 42, 44, 46, 48, 50, 52 | 6 | 18 | 6 |
| 4 | 180, 185, 190, 195, 200, 205 | 3 | 16 | 0 |
| 5 | 50, 53, 56, 59, 62, 65 | 3 | 18 | 0 |
| 6 | 14, 17, 20, 23, 26, 29 | 3 | 18 | 0 |
| 합계 | 38개 프레임 | 28 | 112 | 17 |

타자 박스는 38개입니다. 공 위치가 불명확한 10개 프레임은 `uncertain`, 좌표는 null입니다. 보이지 않는 프레임을 공이 없는 음성 표본으로 취급하지 않습니다. 손에 들고 있는 공과 비행 중인 공은 `ball.note`로 구분합니다.

관절은 좌우 어깨·골반·무릎 6개 항목 중 식별 가능한 가까운 쪽을 표시했습니다. 반대편은 몸에 가려져 신뢰성 있게 위치를 정하기 어려우므로 비워두었습니다. 따라서 **완전한 양측 포즈 정답이나 존 높이 정답은 아닙니다.** 1·4번은 타자가 작아 특히 재검토가 필요합니다. 좌우는 타자 본인 기준의 시각적 초안이며 독립 검토 전입니다. 옷에 가려진 관절 중심의 추정 오차가 포함됩니다.

좌표 허용폭 5~8px는 작업상 추정치이며 측정한 정확도가 아닙니다. 모든 라벨은 `review_status=draft`, `independent_review=false`입니다. 홈플레이트 경계·존·스트라이크/볼은 미확정으로 유지합니다.

## 분석 입력

- 목록: `data/releases/testset-v003/manifest.json`
- 원본 추출 이미지: `data/derived/testset-v003/<video_id>/original/`
- **분석용 이미지:** `data/derived/testset-v003/<video_id>/analysis/`
- 포인터 보정 마스크: 같은 경로의 `cursor-mask/`
- 분석 제외 마스크: 같은 경로의 `ignore-mask/`
- 라벨: `data/labels/testset-v003/<video_id>.jsonl`
- 수동 입력 기록: `data/labels/testset-v003/manual-review.json`
- 원본/보정본·라벨·제외 영역 비교 화면: `data/derived/testset-v003/review.html`

manifest의 `image_path`는 항상 **포인터 보정 PNG**입니다. `original_image_path`는 검토용입니다. 크기·프레임 번호·좌표계를 유지했으므로 좌표 변환 없이 같은 라벨을 사용합니다. PNG에 라벨을 그려 넣지 않았습니다. 비교 화면과 `outputs/issue10/labeled-v003/`의 시각화만 라벨을 표시합니다.

`scripts/prepare_manual_dataset.py`의 `iter_analysis_frames()`는 보정 이미지·제외 마스크·라벨을 반환하며 원본으로 자동 대체하지 않습니다. 이후 #11~#13 모듈은 이 입력을 사용하고 제외 마스크와 겹치는 검출의 근거를 제거해야 합니다. 아직 모델 분석 실행기에 연결된 상태는 아닙니다.

```python
from scripts.prepare_manual_dataset import iter_analysis_frames

for image, ignore_mask, label in iter_analysis_frames(
    "data/releases/testset-v003/manifest.json"
):
    # image: 포인터 보정 BGR 이미지
    # ignore_mask: 0=사용 가능, 255=보정 또는 UI 영역이므로 제외
    # 검출 박스/공 영역이 마스크와 겹치면 평가 근거로 사용하지 않음
    pass
```

저장소 루트에서 실행합니다. 선택 프레임의 간격은 일정하지 않습니다. 이 PNG 목록을 고정 FPS 동영상으로 간주하거나 화면 녹화 시간을 실제 공의 비행 시간으로 사용하지 않습니다.

## 보정 방식과 검증

사용자 요청에 따라 OpenCV Telea 방식으로 수동 지정한 포인터 윤곽 주변만 보정했습니다. 원래 배경을 복원했다는 보장은 없으므로 **보정된 모든 픽셀을 분석 제외 마스크에도 기록**했습니다. 공·타자 영역과 포인터 마스크가 겹치면 생성 스크립트가 중단하도록 했습니다. 선택 프레임에서는 해당 충돌이 없었습니다.

포인터가 없는 21장은 원본 추출 이미지와 픽셀 단위로 같습니다. 보정한 17장도 마스크 바깥 픽셀은 완전히 같습니다. 원본 영상 6개의 SHA-256이 이전 manifest와 같고, 출력·라벨·수동 기록 159개 파일의 해시를 검증했습니다.

중앙 재생 버튼·자막 등은 지워서 공을 만들어내지 않고 제외 마스크로 기록했습니다. 특히 6번의 17·20·23번 프레임은 공과 재생 UI의 겹침 때문에 공 중심을 비워뒀습니다. 제외 마스크는 이번 선택 프레임의 확인된 UI 영역용이며 범용 UI 검출기가 아닙니다.

```powershell
# 실제 자료를 받은 뒤 검증
.venv/Scripts/python.exe scripts/prepare_manual_dataset.py --validate data/releases/testset-v003/manifest.json

# 오프라인 검토 화면 재생성
.venv/Scripts/python.exe scripts/render_manual_review.py
```

처음 생성할 때는 `scripts/prepare_manual_dataset.py`를 인자 없이 실행합니다. 기존 manifest는 덮어쓰지 않습니다. 새 주석으로 자료를 재생성할 때는 수동 기록도 새 버전 경로에 복사하고 `--annotations`와 `--version`을 함께 지정합니다. 원본 영상과 실제 라벨·보정본·검토 화면은 Git에서 제외합니다. 팀 공유 위치는 미정입니다.
