# 초기 공통 테스트 자료 v1

이슈 #10의 로컬 초안입니다. 실제 영상·프레임·라벨·manifest는 Git 제외 경로에만 저장하며 공유 위치와 이용 조건은 #4에서 확인합니다.

## 준비한 항목

- 제공된 5개 파일의 해상도, 파일 FPS, 프레임 수, SHA-256 조사 및 로컬 원본 복사본 검증
- 각 파일의 장면을 확인한 contact sheet와 개발용 투구 구간 5개 선정
- 원본 프레임과 연결되는 미리보기 5개 및 변환 기록
- 기준 영상 1개의 공 중심·타자 박스 수동 초안 8프레임
- 확인할 수 없는 홈플레이트 앞변·존·관절·판정은 null/미주석 상태 유지
- [촬영 가이드](capture-guide.md) 작성

## 샘플 범위

| ID | 크기 | 파일 프레임 수 | 선택 원본 프레임(양끝 포함) | 용도 |
| --- | --- | --- | --- | --- |
| import20261029_c01_v001 | 1006×1534 | 247 | 0~100 | 야외 투수 뒤쪽, 작은 타자·공 사례 |
| import20261029_c01_v002 | 906×770 | 131 | 0~44 | 기본 공·타자 가시성, 기준 수동 라벨 |
| import20261029_c01_v003 | 842×766 | 148 | 25~70 | 스윙·가림 사례 |
| import20261029_c01_v004 | 980×1762 | 281 | 125~235 | 실내·움직이는 시점·작은 타석 사례 |
| import20261029_c01_v005 | 810×986 | 149 | 25~85 | 중계 그래픽·카메라 이동 사례 |

프레임 번호는 0 기반입니다. 선택 범위는 개발용 문맥 구간이며 릴리스·포구·홈플레이트 통과 시점의 정답 라벨이 아닙니다. 5개 모두 파일상 30fps이며 원래 촬영 FPS·재생 배속·원출처는 확인되지 않았습니다. 재생 버튼 등으로 화면 녹화로 분류했으며 실제 비행 시간을 계산하면 안 됩니다.

v002/v003은 동일 중계 출처일 가능성이 있어 같은 split_group_id로 보수적으로 묶었습니다. 나머지도 촬영 세션이 확인되지 않았으므로 전체 자료를 development_only로 두고 학습/검증/최종 평가 분할에 사용하지 않습니다.

## 수동 라벨 범위와 한계

v002의 프레임 24, 26, 28, 30, 32, 34, 36, 38을 확대 관찰해 공 중심과 타자 박스를 표시했습니다. 추론 모델 결과를 정답으로 사용하지 않았습니다. 공 중심의 약 5px 허용폭은 작업상 추정치로 측정된 정확도가 아닙니다. 포구에 가까운 38번은 우선 재검토 대상입니다.

`review_status=draft`, `independent_review=false`로 유지합니다. 라벨 없는 프레임은 음성 표본이 아니라 미주석입니다. 관절의 좌우 해부학적 구분·홈플레이트 앞변은 신뢰할 수 없어 비워두었습니다. 이 자료는 타자 선택과 공 검출의 초기 개발용이며 존 높이·실제 판정 정확도 평가 세트가 아닙니다.

v002/v003의 미리보기는 위쪽 관중석·아래쪽 UI를 줄이는 공간 크롭을 적용했습니다. 프레임 위치별 내부 재생 버튼은 남아 있고 포인터를 생성형 보정으로 지우지 않았습니다. 나머지는 공간 크롭 없이 시간 구간만 잘랐습니다. 원본 좌표에서 라벨을 작성했으므로 미리보기에 그릴 때 crop 원점을 빼야 합니다. 파생본은 무음 mp4v이며 해시는 원본과 별도입니다.

## 추가 자료: testset-v002

6번째 영상(import20261029_c01_v006)을 추가했습니다. 984×724, 파일상 30fps, 104프레임이며 개발용 구간은 0~47(양끝 포함)입니다. 타자가 자세를 낮추는 장면, 중앙 재생 UI, 카메라 이동이 있어 자세 변화·가림 사례로 사용합니다. 실제 스윙/번트 여부와 판정 정답은 라벨링하지 않았습니다.

기존 v001 파일·라벨은 변경하지 않았습니다. 최신 `data/releases/testset-v002/manifest.json`은 기존 5개 파일과 신규 파일을 함께 참조하므로 배포 시 manifest에 나열된 v001/v002 경로를 모두 포함해야 합니다. 신규 파일의 원출처·촬영 FPS·사용 조건도 미확인입니다. 새 영상의 수동 좌표 라벨은 아직 없으며 기존 8프레임 라벨을 재사용합니다.

v002 전체 33개 파일의 해시와 신규 미리보기 48프레임 디코딩을 확인했습니다. 추가 원본은 `data/raw/testset-v002/`, 미리보기는 `data/derived/testset-v002/`에 있습니다.

## 후속 자료: testset-v003

6개 영상의 선택 프레임 38장에 공·타자·식별 가능한 관절의 수동 초안을 작성하고, 포인터가 보이는 17장은 해당 영역만 OpenCV로 보정했습니다. 기존 v001/v002는 보존했습니다. 현재 선택 프레임 분석은 v003 manifest의 보정본과 제외 마스크를 사용합니다. [수동 라벨과 분석 입력 안내](manual-labeling.md)를 참고하세요.
