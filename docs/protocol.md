# 스마트폰–노트북 통신 규격
상태: 미확정. 폰 1대 + 노트북을 대상으로 하며 제안서의 TCP 통신을 출발점으로 검토합니다. 아래 목록은 구현된 프로토콜이 아닙니다.

## 합의할 항목
- 연결 시작·종료, 서버 주소·포트, 재접속
- 메시지 종류, 버전, 길이 구분, 헤더와 payload 구조
- 영상 인코딩·해상도·방향과 압축 설정
- 투구·프레임 식별자, 촬영 시각과 전송 시각의 구분
- 연속 영상 또는 투구 구간 전송 방식, 대기열·지연 처리
- 존·공 좌표와 판정 결과의 필드, 단위, 오류 응답
- STRIKE / BALL / 판정 불가 / 스윙 제외의 전송 값
- 결과 중복·누락·오래된 결과 처리

## 확정 절차
앱·서버 담당자가 Issue/PR에서 예시 요청·응답과 실패 처리를 합의한 뒤 이 문서를 갱신합니다. 좌표·시간 정의는 [coordinates.md](coordinates.md)와 일치시킵니다.
